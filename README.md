# Nimi

### Nelilaskin

## Kuvaus

Nelilaskimella voi laskea yhteen-, vähennys-, kerto- ja jakolaskuja ja lisäksi laskea neliöjuuren.
Laskin on kehitetty läheisen tarpeesta saada laskin, jonka värejä voi muokata mieleisiksi.
